# Ai Nobiloption — project notes

The standing brief in `~/.claude/CLAUDE.md` applies in full. This file records
only what differs, so a future session does not try to rebuild the Vite setup
that was removed on 2026-10-20.

## Stack

**Next.js 16 App Router**, static export. This project is the Next.js
exception to the "React + Vite" default in the global brief.

```
app/
  layout.jsx            root shell: fonts, metadata, header/footer, GA
  globals.css           the whole design system, one file
  page.jsx              home
  <route>/page.jsx      one directory per route
  not-found.jsx         becomes 404.html
src/
  components/           all UI, shared by the pages above
  data/                 content.js and seo.js, unchanged from the Vite build
  hooks/                scroll-reveal, scroll-spy, count-up
  lib/                  metadata mapping, phone helpers, lead submission
```

`next.config.mjs` sets `output: 'export'` and `trailingSlash: false`. Routes
build to `out/<route>.html`, which keeps the canonical URLs identical to the
entries in `sitemap.xml` (no trailing slash) and lets Vercel serve `/about`
straight from `about.html`. `out/404.html` gives an unknown path a real 404
status.

Build with `npm run build`. The output is `out/`, not `dist/`; both are
gitignored.

## Rules that are easy to break here

- **`'use client'` is required** on anything with a hook. Currently: `Header`,
  `RegistrationForm`, `PhoneNumberInput`, `Faq`, `FaqPage`, `CountUp`,
  `RevealProvider`, `ScrollHandler`. Adding a hook to a server component fails
  the build with a message about event handlers crossing the boundary.
- **No event handlers on server components.** The About page used to hide a
  broken image with `onError`; that is not renderable on the server and was
  removed.
- **Prerendered content must stay visible without JS.** `globals.css` hides
  `.reveal` only under `html.js`, and `app/layout.jsx` adds that class from an
  inline script before the body parses. Do not reintroduce a bare
  `.reveal { opacity: 0 }` - it would blank the page for a crawler.
- **Metadata comes from `src/lib/metadata.js`**, which maps `src/data/seo.js`
  onto Next's Metadata API. Do not hand-write head tags in a page.
- **Noindex routes carry no canonical.** `pageMetadata()` already omits it when
  `canonical` is null. The not-found page drops `robots` too, because Next adds
  its own and two tags end up in the HTML.
- **Legacy redirects live in `vercel.json`.** `redirects()` in
  `next.config.mjs` is unsupported with `output: 'export'`.
- **`AGENTS.md` at the repo root is generated by `next dev`.** Removing it only
  re-creates it; commit it with the rest of the work.

## Verifying

Several Zeetech projects share this machine, so more than one `next dev` or
`vite preview` is often already listening. Before testing, confirm the server
is serving *this* site:

```bash
curl -s http://localhost:<port>/ | grep -o '<title>[^<]*'
```

It must say "Ai Nobiloption". A port serving another project returns 200 and
looks fine, which is how a whole audit ends up measuring the wrong site.

Next itself refuses to start a second dev server for the same directory and
prints the port of the one already running - use that instead of picking a new
port.
